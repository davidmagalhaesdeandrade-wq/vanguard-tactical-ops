# VANGUARD: Tactical Ops

FPS tático 3D original para navegador, desenvolvido com Three.js e Vite.

## Executar

```bash
npm install
npm run dev
```

## Produção

```bash
npm run build
npm run preview
```

## Estado atual

Estrutura inicial do projeto. Em implementação: mapa jogável, personagens, armas, IA de bots, HUD e modos.
